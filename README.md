# 暗区突围无限 · 拖动声音识别器（声音识别）

面向 **《暗区突围：无限》** 的实时**拾取物声音识别**工具。
你在仓库或对局里「拿东西」时，它听声音告诉你拿到的是什么——省去肉眼分辨和查价的时间。

> 📖 完整说明见 **[暗区行商声音辨识度软件_使用说明.md](./暗区行商声音辨识度软件_使用说明.md)**（含算法参数、全部配置项、故障排查）

---

## ✨ 功能特性

| 模块 | 说明 |
|---|---|
| 🔍 实时声音识别 | 三种模式：**单次模式 / 持续模式 / 持续模式+左键触发**（默认最后一种，每次左键单击识别一次） |
| 🪟 悬浮窗 | 置顶显示识别结果与状态标识，1～6 件卡片布局，外观与主界面独立设置 |
| 🎚️ 筛选栏 | 悬浮窗可按「物品分类 / 物品格数 / 稀有度」筛选 |
| 📚 物品资料库 | **299 件物品**（红 36 / 金 68 / 紫 72 / 蓝 70 / 白 53），支持搜索、排序、新增、编辑、上传图片 |
| 🔊 声音组 | 把「听起来一样」的多个物品设为一组共用样本 |
| 🎙️ 样本采集 | 分别录制「仓库样本」与「对局内样本」，两类识别时合并使用；每组建议录 3～5 次 |
| 🧩 失败片段复核 | 未识别片段自动存档，可试听、人工标注、或标记为环境音 |
| 📊 识别诊断 | 起音 / 背景差 / 录音峰值 / 最佳候选距离 / 候选差距 / 算法 / 有效模板数 |
| 💾 资料库管理 | 统计占用、清理未引用样本、备份为 ZIP、导入备份（保留/替换） |
| 🎨 外观自定义 | 3 套主题：现有风格·翡翠绿 / 现代简约·黑白钴蓝 / 铂金典藏·黑白香槟金 |
| ⌨️ 全局快捷键 | 「开始检测」可绑 F1～F24、字母数字、左右 ALT/CTRL/SHIFT 组合 |

## 🚀 快速上手

1. **解压整个文件夹**（不要只提取 exe，必须连同 `_internal\` 一起）。
2. 双击 `听声软件\SoundRecognizer\SoundRecognizer.exe`（或 `听声软件\声音识别.lnk`）。
3. 等待界面提示 **「声音样本准备完成，可直接开始检测」**（程序会自动预热样本，无需先点开始检测）。
4. 打开《暗区突围：无限》，回到软件点 **「开始检测」**。
   - 状态栏显示 **「监听已连接：（48000Hz，…）」** 表示音频通道打通。
5. 在游戏里正常拾取物品，**按下鼠标左键**即自动截取并识别，结果出现在悬浮窗。
6. 想结束点 **「停止检测」**。

> 💡 **隐藏功能**：在版本标签上**快速点击 5 次**可解锁「物品资料库」标签页。

## 💻 运行环境

本程序为 **绿色免安装** 的 Windows 桌面程序（Python 3.8 + Tkinter，PyInstaller onedir 打包）。

| 项目 | 要求 |
|---|---|
| 操作系统 | **Windows 64 位**（建议 Win10 / Win11 x64） |
| Python / Node / .NET | **都不需要**，全部已内置 |
| VC++ 运行库 | 无需安装（已内置 `VCRUNTIME140.dll`、`ucrtbase.dll`） |
| 音频 | 需支持 **WASAPI 环回（Loopback）**；录的是「系统输出」，**不需要麦克风** |
| 权限 | 不需要管理员权限 |
| 磁盘 | 完整版约 **584 MB**，建议预留 ≥ 2 GB |
| 端口 | 不占用任何端口（无网络服务） |

## ⚙️ 默认配置要点

| 配置键 | 默认值 | 说明 |
|---|---|---|
| `recognition_mode` | `持续模式+左键触发` | 每次左键单击检测一次 |
| `capture_duration_ms` | `800` | 检测时长，可调 200～2000 毫秒 |
| `audio_source_mode` | `系统输出` | WASAPI 环回默认播放设备 |
| `audio_gain_db` | `"0"` | 采集增益 |
| `start_shortcut` | `"0"` | 全局快捷键（`"0"` = 未设置） |
| `overlay_topmost` | `true` | 悬浮窗置顶 |
| `ui_theme` | `jade` | 现有风格·翡翠绿 |

**核心识别参数**（不可界面调整，见 `_internal/assets/algorithm_provenance.md`）：
16 kHz 重采样 / 49-tap sinc / 300·1500 Hz 双高通 / 100·180 ms 滑窗 / 30 ms 步长 /
550 ms 参考前缀 / 420 ms 查询前缀 / **相关性阈值 0.70** / **组间间隔阈值 0.04**

## ❓ 常见问题

| 问题 | 处理 |
|---|---|
| 无声 / 监听失败 | 确认**系统默认播放设备**正确；程序会自动尝试多种采样率、声道数和环回设备；可在设置里手动选设备 |
| 识别不准 | 看「诊断详情」定位原因；重录样本；把相似物品设成同一**声音组**；**不要把环境声存进样本库** |
| 没反应 / 打不开 | 必须带 `_internal\` 文件夹一起，不能只提取 exe |
| 杀毒误报 | PyInstaller 程序常见误报，加信任区即可 |
| 快捷方式失效 | 换机器后 `.lnk` 里的绝对路径会失效，右键 exe 重新创建即可 |

更详细的排查见 **[完整说明书](./暗区行商声音辨识度软件_使用说明.md)** 第十三章。
